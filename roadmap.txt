# TRUTH-SURFACE DOCTRINE (architectural rule -- never violate)

Argus has three truth classes:

  1. Canonical execution truth
     orders, fills, account, positions, decision events, decision_trace

  2. Deterministic lifecycle truth
     trade lifecycle records rebuilt from canonical truth (trade_journal)

  3. Analytical truth
     latency, slippage, attribution, equity curves, risk metrics, reports

Rules:
  - lower layers feed higher layers only
  - higher layers never mutate lower layers
  - analytics must never become hidden runtime control state
  - every derived metric must be traceable to its source artifact

# GLOBAL INVARIANTS (binding contracts -- every system, every strategy)

## Payoff Contract
  Every strategy must define before paper trading begins:
    - Min target move (pips, bps, or USD)
    - Target reach rate: % of trades that hit TP. Kill if < 25%.
    - Timeout rate: % of trades that expire at max hold. Kill if > 60%.
    - Stop rate: % of trades that hit SL. Kill if > 2x target rate.
    - MFE tail check: median MFE must exceed 1.5x cost to confirm real edge.
    - Costs from day one: all backtests and paper runs include realistic fees,
      spread, and slippage. No "add costs later" allowed.

  Template:
    Strategy: _______________
    Venue/Pair: _______________
    Min target move: _______________
    Expected target reach rate: _____ % (kill < 25%)
    Expected timeout rate: _____ % (kill > 60%)
    Expected stop rate: _____ % (kill > 2x target rate)
    Median MFE vs cost: _____ x (kill < 1.5x)
    RT cost model: _____ bps/pips

## Execution Contract
  Every strategy must define:
    - Venue and instrument
    - Fee structure (maker/taker, per-side, RT total)
    - Spread model (median, P95, widening conditions)
    - Slippage model (expected vs worst-case)
    - Fill rate (% of signals that execute)
    - Latency budget (signal-to-fill target)

## Kill Discipline
  - Payoff Contract fail = kill. No exceptions, no "one more week".
  - Execution delta > 25% vs model = kill.
  - 3 consecutive weeks negative with >= 15 trades/week = kill.
  - Drawdown > 3x model (paper) or > 2x model (live) = kill.
  - Kill = archived permanently. Strategy name retired. No resurrection.

## Phase C Rollback Rules
  - ONE variable per cycle. Never two simultaneous experiments.
  - Minimum 5 days or 20 signals per cycle (whichever comes first).
  - Revert if EV drops > 20% vs baseline.
  - No simultaneous experiments across strategies within same system.

# PROMOTION PIPELINE (Research -> Paper -> Live -> Scale)

## Research -> Paper gate:
  - Payoff Contract defined and passing in backtest
  - 7/7 stress suite pass (gap, spread spike, news, low liquidity, trending,
    ranging, overnight)
  - 14+ days of backtest data minimum
  - 100+ signals in backtest

## Paper -> Live gate:
  - 30+ paper trades (acknowledge this is noisy evidence, not proof)
  - Expectancy within 20% of backtest expectancy
  - Replay-Live Divergence Guard passes (see below)

## Live -> Scale gate:
  - 30+ live fills
  - Slippage within model bounds
  - Expectancy within 30% of paper expectancy

## DEMOTION paths:
  - Live -> Paper: on 20% expectancy degradation (watch trigger, not instant kill)
  - Scale -> Live: on drawdown > 1.5x model

---

# REPLAY-LIVE DIVERGENCE GUARD

  Purpose: Detect when paper/live execution diverges from backtest assumptions.

  Metrics monitored:
    - Entry price delta (backtest vs paper/live)
    - Signal timing delta (bar alignment)
    - Expectancy delta: 20% = alert, 25% = kill
    - Hit rate delta: 10pp = alert, 20pp = kill
    - Timeout rate delta: 15pp = alert

  Status: NOT YET BUILT. Required before any Paper -> Live promotion.

# GLOBAL RISK BUDGET

  Allocation limits:
    - Max single system allocation: 50% of capital (paper), 70% (live)
    - No single strategy > 80% of trailing 30-day PnL

  Correlation budget:
    - EUR/USD + GBP/USD count as 1.5 systems, not 2 (correlated USD risk)
    - Correlated pairs share a combined drawdown limit

  Per-system drawdown limits:
    - > 3x model = pause (paper)
    - > 2x model = pause (live)
    - > 1.5x model = reduce scale 50%

  ML Governor rules:
    - Never primary decision path. Advisory only.
    - LOG_ONLY until proven incremental over deterministic rules.
    - Retrain requires 30+ single-config trades. Mixed-config training forbidden.
